# Notes for Claude

This is a personal research project, not code. Ondrej and Nesli are looking for a community and land to root themselves in.

## Rules

- Read `us/profile.md` and `us/criteria.md` before any research. They are the source of truth for what we want.
- Use plain, simple English. Short sentences. Prefer lists and tables.
- New place → copy `places/_template.md`. New region → copy `regions/_template.md`. New visit → copy `visits/_template.md`.
- Always add sources (links) for facts. Mark guesses as guesses.
- Note the date when you add facts (prices, laws and projects change).
- Don't delete dropped places. Set status to `dropped` and write why.
- When our wishes are unclear, use the `grilling` skill to ask us, don't assume.
